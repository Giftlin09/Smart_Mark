Quick Start Guide

  1. Classes 1 through 12 are available in the dropdowns.
  2. Add students manually or import via CSV and PDF with Admission Numbers.
  3. Click Edit to update a student's name or admission number directly in the roster table.
  4. Enter marks for each subject in Mark Entry. All subjects for an exam automatically appear side-by-side in the Consolidated Sheet.
  5. Check Grade Analytics to view precise performance distribution across all 9 scales.
  6. Generate reports and export to CSV, Word (.doc), Apple Pages (.rtf), PDF, or Print.
