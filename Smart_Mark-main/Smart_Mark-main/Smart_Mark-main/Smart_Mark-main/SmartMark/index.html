Quick Start Guide

  1. Classes 1 through 12 are available in the dropdowns.
  2. Add students under Classes & Roster or import via CSV/PDF with Admission Numbers.
  3. Enter marks for each subject in Mark Entry. Term pattern supports internal marks (NBS, SE, T).
  4. Use Print Reports for single-subject individual report cards.
  5. Use Consolidated Sheet to view all subjects side-by-side with automatic totals based on the number of subjects, subject averages, and clear fail highlighting.
